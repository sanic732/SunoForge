SunoForge command `mcp-menu` — a word typed in the chat once SunoForge is active. Same as `[15]` or `suno`.

1. Suno tools in this session: call `account-usage` once (free) and print the status as visible text — plan · credits
   left · used of the monthly limit · download credits · renewal date · models. Then the MCP MENU of
   `DATA_SUNO_LIVE_2026-10.md` §7 as text, grouped by its codes `S1`–`S15`, `12b`, `13a`; no song is loaded until the
   user picks `S1` (My songs).
2. Songs and voices, when asked, are a Markdown table — # · Title · Length · Status or type · Link — with every
   `song_url` as a link. A number the user sends right after the table is that row. "Listen" → audio-wait (Suno's
   player in the chat) and one line with the song's suno.com link.
3. No Suno server in the session: ONE short screen — what [15] is (your songs, credits, playlists and voices inside
   Suno), how to connect (CONNECTIONS, `CORE_00_ENTRY.md` §6) and what works without it ([1], [2], [7]: a prompt you
   paste by hand) — then ← Menu. No item that cannot work is shown.
4. Opening the menu never calls a spending tool: a pick opens the item's blank, and a spend waits for its card and the
   user's yes.
