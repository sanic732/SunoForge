# SunoForge v3.0 — AI Music Prompt Orchestrator

`[RU]` этот файл · `[EN]` [README.md](README.md)

Набор инструкций, превращающий любого чат-ассистента в промпт-инженера для
генерации музыки. Двенадцать файлов, пять платформ, один принцип: **не выдавать
догадку за факт**.

Работает в Claude, Gemini, ChatGPT, Grok и любом ассистенте, куда можно вставить
большой текст или приложить файлы.

**Попробовать без установки** — готовый бот в Gemini, всё уже загружено:
[SunoForge v3.0](https://gemini.google.com/gem/17bBfa7ucT2IjbKVLxPjz7NRuy8LSixdE?usp=sharing)

## Чем v3.0 отличается от прошлых версий

Три независимые проверки фактов 27.07.2026 показали, что обе прошлые сборки
подавали комьюнити-догадки тоном документации. Проверка сняла с системы четыре
несущие конструкции:

| Что было | Что оказалось |
|---|---|
| **MAX MODE** — «режим скрытого качества» | Режима нет. Контролируемое сравнение не нашло разницы |
| **Two-Minute Drift** — «треки деградируют после 2 минут» | Только анекдоты. Ни тестов, ни признания вендора |
| **Теги `[Reverb: 30%]`, `[BPM: 120]`** | Никогда не парсились ни одной платформой |
| **Лимит поля Style «200 символов»** | Неверно. Резало промпт вдвое ниже рабочего диапазона |

Отсюда два принципа, на которых стоит v3.0.

**Разметка достоверности.** Каждое утверждение о поведении платформы несёт метку
`[OFFICIAL]` (документация вендора), `[COMMUNITY]` (независимые тесты и гайды)
или `[UNVERIFIED]` (повторяется, первоисточника нет). Утверждение без метки —
дефект.

**Разделение CORE и DATA.** Правила и факты живут в разных файлах, потому что
гниют с разной скоростью. С марта по июль 2026 сломались все платформенные факты
— версия модели по умолчанию, длина трека у Lyria, имя Flow Music, версия Studio,
механика стемов, редактор лирики, а два продукта закрылись совсем. **Ни одно
правило промптинга за тот же период не сломалось.** Поэтому обновление — это
замена одного файла `DATA_*`, а не пересборка всего.

## Платформы

- **Suno** — вокал с характером, свой голос, модель на своём каталоге, полный редактор
- **Google Lyria 3** Pro / Clip / RealTime — единственная платформа с официальным гайдом по промптингу
- **Google Flow Music** — правка трека по частям без перегенерации
- **ElevenMusic** — лицензированные данные, смена жанра внутри трека, регенерация секций
- **Stable Audio 3.0** — открытые веса, самая длинная одиночная генерация, выход принадлежит вам

Udio не является целевой платформой: после мирового соглашения скачивание
отключено. Остаётся в системе как поучительный кейс.

## Быстрый старт

1. Открыть ассистента с длинным контекстом.
2. Загрузить содержимое `files/` — все двенадцать файлов, или пятью файлами `CORE_*` плюс архив `DATA_*` (см. [docs/GEMINI.md](docs/GEMINI.md)).
3. Написать `старт` или `/menu`.
4. Дальше — пункт меню или просто задача своими словами.

Подробно: [docs/БЫСТРЫЙ_СТАРТ.md](docs/БЫСТРЫЙ_СТАРТ.md) ·
для опытных: [docs/ДЛЯ_ПРОФИ.md](docs/ДЛЯ_ПРОФИ.md)

## Как пользоваться

Номер пункта меню называть не обязательно — можно просто описать задачу, система
сама определит маршрут:

| Вы пишете | Куда уходит |
|---|---|
| «тёмный кинематографичный трек с виолончелью» | Быстрый старт, 2–3 варианта |
| «хочу похоже на вот этот трек, но медленнее» | Клонирование стиля `[3]` |
| «смешай фонк и джаз» | Гибридная лаборатория `[4]` — подберёт мостовой жанр |
| «нужна хриплая женская вокалистка» | Мастерская персон `[5]` — биография вместо тега |
| «нужен трек на 5 минут» | Сравнение платформ `[10]` |
| «вот мой промпт, почему звучит плохо» | Аудит `[12]` — диагноз и починка |
| «это можно монетизировать?» | `/legal` |

На каждый запрос система даёт **2–3 интерпретации**, а не один «правильный»
ответ. Меняется обычно жанр, а настроение и вокал остаются — так получаются
разные пластинки из одного замысла.

## Настройка ядра под себя

Все настройки — в начале файла `files/CORE_00_ENTRY.md`, блок `<preloader>`.
Отредактируйте значения прямо в файле перед загрузкой либо меняйте на ходу
командами `/set`.

```
HOST_MODEL       = "auto"     // auto | claude | gemini | gpt | grok
TARGET_PLATFORM  = "auto"     // auto | suno | lyria | flow | eleven | stable | dual | all
SUNO_VERSION     = "v5.5"     // v5.5 | v5 | v4.5-all (бесплатный тариф)
LYRIA_MODEL      = "pro"      // pro | clip | realtime
DURATION         = "auto"     // auto | нужная длина трека
OUTPUT_LANG      = "ru"       // ru | en — язык объяснений
VARIANT_COUNT    = 2          // 1 | 2 | 3 — сколько вариантов на идею
USER_LEVEL       = "auto"     // auto | beginner | pro — глубина объяснений
SESSION_MODE     = "creative" // creative | technical | clone
VOICES_ENABLED   = false      // true, если Suno Pro/Premier и голос загружен
CUSTOM_MODEL     = ""         // имя вашей обученной модели Suno
SHOW_CONFIDENCE  = true       // показывать метки достоверности
FOLKLORE_MODE    = "off"      // off | on — неподтверждённые приёмы
```

**Что менять в первую очередь**

- `OUTPUT_LANG` — на каком языке система объясняет. Сами промпты всегда
  английские: платформы понимают английский лучше.

  ⚙️ Релиз выложен двумя архивами, `_ru` и `_en`, но **выбирать по языку не
  обязательно**: они содержат одни и те же двенадцать файлов и отличаются ровно
  этой строкой. Что скачали, то и подойдёт — язык переключается командой
  `/set lang ru` или `/set lang en` в любой момент.
- `TARGET_PLATFORM` — если работаете только с одной платформой, поставьте её
  и не будете получать лишние варианты. `all` — одна идея сразу для всех.
- `VARIANT_COUNT` — поставьте `1`, если точно знаете, чего хотите, и `3`, если
  ищете идею.
- `SUNO_VERSION` — на бесплатном тарифе поставьте `v4.5-all`, иначе система
  предложит функции, которых у вас нет.

**Тонкие настройки**

- `SHOW_CONFIDENCE = false` уберёт метки `[OFFICIAL]`/`[COMMUNITY]` из ответов,
  если они мешают читать. Проверять достоверность система не перестанет — просто
  не будет показывать.
- `FOLKLORE_MODE = "on"` вернёт неподтверждённые приёмы вроде MAX MODE. Они
  по-прежнему будут помечены как неподтверждённые. Включайте, если хотите
  сравнить сами.
- `USER_LEVEL = "pro"` уберёт пояснения и оставит только промпты.

Те же параметры на ходу, без правки файла:

```
/set lang ru          /set platform suno       /set variants 3
/set suno v4.5-all    /set duration 3:30       /confidence off
/set lyria clip       /folklore on             /menu
```

**Слой CORE — правила. Не датированы, живут годами.**

| Файл | О чём |
|---|---|
| `CORE_00_ENTRY.md` | Preloader, меню на 12 пунктов, маршрутизация, форматы вывода, разметка достоверности |
| `CORE_01_STYLE.md` | Шестислойное построение Style, Time & Place, персоны, гибриды, клонирование стиля |
| `CORE_02_LYRICS.md` | Секционные метки, нотация исполнения, ад-либы, дуэт, аккорды, два пути разметки |
| `CORE_03_DIAGNOSE.md` | Движок починки промптов: 14 проверок и 19 строк замены мёртвых конструкций |
| `CORE_04_WHY.md` | Почему каждое правило устроено так. Грузится по `/why` |

**Слой DATA — факты. Датированы, обновляются поквартально.**

| Файл | О чём |
|---|---|
| `DATA_SUNO_2026-07.md` | Версии, поля, слайдеры, свой голос, свои модели, стемы, тарифы |

| `DATA_POSTPROD.md` | Цепочка мастеринга, стемы, передача в DAW, громкость |
| `DATA_LEGAL_2026-07.md` | Права, согласия, иски, политики площадок. Грузится по `/legal` |
